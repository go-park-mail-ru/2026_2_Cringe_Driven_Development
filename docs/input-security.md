# Защита пользовательских данных

## SQL

Передавайте пользовательские значения через аргументы pgx. Для динамических
SQL-идентификаторов и вариантов сортировки используйте фиксированный список.
Репозиторий блокнотов проверяет владельца при чтении и изменении. Берите
блокировку строки до изменения ячеек, сохраняя проверку ревизии и владельца
внутри операции. Чужой блокнот получает 404.

## XSS и CSRF

Go возвращает JSON. Имя блокнота, исходник ячейки и текстовый вывод сохраняются
без HTML-преобразований. Безопасная вставка текста в DOM и обработка HTML
относятся к frontend. Проверяйте браузерное отображение там при изменении
рендерера.

Браузер отправляет сессионную cookie BFF. BFF отвечает за браузерные CSRF и CORS.
Go получает Bearer, а refresh принимает в JSON. Перед разбором тела и Bearer
проверяется ровно один `X-BFF-Key`. `GET /health` доступен для проверки
готовности. [Авторизация](authentication.md).

## Проверки

`make test` включает проверки параметризации, валидации и S2S. Для
блокнотов дополнительно проверьте строку с кавычками и угловыми скобками на пути
редактор → JSON → PostgreSQL → экспорт IPYNB. Проверьте браузерный вывод через
BFF и отказ чтения чужого блокнота на двух тестовых пользователях.
