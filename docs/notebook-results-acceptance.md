# Проверка сохранения результатов исполнения

- Выполнить ячейку, открыть блокнот повторно и сверить вывод с экспортом IPYNB.
- Изменить исходник до завершения исполнения. Устаревший результат не должен
  перезаписать изменённую ячейку или результат более новой попытки.
- Остановить команды во время dispatch. Проверить завершение остановки и
  сохранение работоспособности kernel.
- Запустить интеграционные Go-тесты с PostgreSQL и тесты агента. Команды —
  в [локальной разработке](local-development.md#проверки-перед-pr).
  Правила записи — в [runtime-сессиях](runtime-sessions.md).
